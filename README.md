# Blitzblick
Blitzblick Spiel für die Mengenerfassung in der Grundschule



Einstellung	Auswahl
Menge	bis 5 · bis 10
Zeit	kurz · mittel · lang
Bild	geordnet (Würfelbilder, Fünfer- und Zweierreihen) · gestreut (schwieriger)
Danach	aufdecken · gleich weiter

Mit Nochmal blitzen erscheint dieselbe Menge noch einmal. Der Knopf Vollbild blendet alles andere am Whiteboard aus. Die Einstellungen merkt sich der Browser.

Bedienung mit Tastatur oder Clicker

Taste	Funktion
Leertaste · Enter · → · Bild ab	weiter
← · Bild auf · R	nochmal blitzen

So lässt sich der Blitzblick auch mit einem Präsentations-Clicker steuern.

Technik

Das Spiel besteht aus einer einzigen Datei (index.html) und braucht keine Installation. Die Datei kann auch heruntergeladen und offline im Browser geöffnet werden. Ohne Internet wird statt der Schrift „Andika“ eine Ersatzschrift angezeigt.
